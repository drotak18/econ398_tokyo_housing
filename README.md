# econ398_tokyo_housing
Repository for ECON 398 project
Examining whether rebuilding residential properties causes an increase in housing prices in Tokyo, using Japanese real estate transaction data and causal methods.
## Data Source

The primary data source for this project is the Ministry of Land, Infrastructure, Transport and Tourism (MLIT) Real Estate Information:

- MLIT Real Estate Information Library (transaction prices):  
  https://www.reinfolib.mlit.go.jp/realEstatePrices/

The analysis will use transaction-level housing data sourced from MLIT.

## Breif Overview 
The project involves examining whether residential rebuilding is associated with higher housing prices in Tokyo using transaction-level real estate data from the Ministry of Land, Infrastructure, Transport and Tourism (MLIT). The analysis will focus on residential property transactions and use information on construction year, transaction price, and sub-location within the city to compare prices between newer and older properties within the same areas and time periods. The main aim of the project is to assess whether higher prices reflect a potential causal effect of redevelopment or whether redevelopment tends to occur in already higher-priced areas.
